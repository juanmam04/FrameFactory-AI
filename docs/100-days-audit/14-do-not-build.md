# 14 — DO NOT BUILD

Cosas tentadoras que **no** necesitamos para publicar los primeros **10** videos.

## DO NOT BUILD

1. **Nuevo generador de imágenes interno** (Replicate/Comfy/LoRA/Kontext 2.0).  
2. **Integración no oficial con Google Flow** (Playwright, scraping, reverse engineering, APIs no documentadas).  
3. **Sistema multi-agente** de research/script/director autónomo.  
4. **NLE / editor de video completo** en web (timeline tipo Premiere).  
5. **Microservicios / cola distribuida / Kubernetes** para un operador humano.  
6. **Reescritura total del frontend** (React/Next) antes de tener Flow Pack + import.  
7. **Publicación automática YouTube** (OAuth, scheduling) antes del Video 10.  
8. **Avatar HeyGen / lipsync** como dependencia del docu stills.  
9. **Validación VLM multi-intento** en el path diario (caro y lento).  
10. **Unificar “bonito” los dos pipelines** en un big-bang refactor.  
11. **Gameplay Minecraft** como base del canal money/power/business.  
12. **Billing Stripe / marketplace** — irrelevante al reto personal 100 días.  
13. **Story Bible LLM perfecta** antes de tener 3 videos publicados.  
14. **Eliminar ya** todo el código visual (perder referencias; borrar después del Video 30+).  

## Principio

Cada hora de ingeniería debe acortar horas humanas del día de publicación **esta semana**, no demostrar arquitectura.
