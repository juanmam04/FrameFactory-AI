# 02 — Documentary workflow

```text
Create project → Topic + research notes + sources
→ Generate / edit script (EN, factual template)
→ APPROVE SCRIPT
→ Flow Pack (visual director + story bible + batches)
→ [Manual Google Flow]
→ Bulk import 001.png…
→ Replace any bad shot
→ Continuous voice (one TTS narration)
→ Preview checks
→ Assemble + render → render/final.mp4
```

Defaults explicitly **excluded**: Reddit mode, POV “Este eres tú”, gameplay, Replicate per-scene, character catalog overlays.

Checkpoints in `project.json`:

`script_ready`, `flow_pack_ready`, `images_imported`, `voice_ready`, `assembly_ready`, `render_ready`
